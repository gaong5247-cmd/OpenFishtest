OpenFishtest — Privacy & retention

This independent chess-engine project is not affiliated with OpenAI, Anthropic, Google or official Stockfish Fishtest.

Public records

Engine names, versions, source URLs, reported chess results, opening-book digests, public worker aliases and selected PGNs may appear on GitHub Pages, API responses, public Issues or Releases. Older records can persist in Git history or external caches.

Uploaded executable files

When operators activate the arena, uploaded engine ZIPs are stored temporarily for an isolated 100-game match. ZIPs scoring under 55/100 or failing validation are deleted locally; their PGNs and public match statistics may remain. A qualifying candidate is kept privately for administrator review. Only the administrator decides which file to publish as a GitHub Release. Submitted software is not guaranteed safe.

Abuse prevention

The API uses connection IP addresses for upload rate limits but stores a locally salted hash rather than a plaintext IP in the arena database. Internet gateways and GitHub may maintain separate access logs under their own policies. Worker access tokens are stored as digests, not plaintext, after one-time issue.

Storage and contact

Local PGNs may be archived after 7 days or under storage pressure. GitHub Releases can keep selected historical PGNs; the 5GB target is not a physical filesystem quota. Never upload personal secrets. For questions, file a non-sensitive issue in the project repository.
