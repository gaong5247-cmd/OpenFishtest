06 / TEST METHODOLOGY

Open results, clear limits.

Stockless is the benchmark, never the presumed winner.

01

Fixed reference

Pinned Stockless version plus SHA-256. Every matchup has a known baseline.

02

Paired openings

Workers use reversed colors and the same starting position for each game pair.

03

Evidence and uncertainty

PGN replay, worker-reported W/D/L, approximate Elo CI and exploratory paired Gaussian SPRT. Not official Fishtest GSPRT.
