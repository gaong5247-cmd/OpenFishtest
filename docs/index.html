03 / THE PRINCIPLES

Built for honest engine testing.

Stockless is the fixed reference, not a guaranteed winner.

01

Fixed anchor

Stockless builds are pinned by version and SHA-256. Results are always attributed to the exact reference used.

02

Equal conditions

Every scheduled match targets paired openings with reversed colors. Execution infrastructure is still being built.

03

Public evidence

Results, game counts, and test conditions should be published. Reported results remain marked unverified until workers can attest to them.
