03 / YOUR PC, YOUR CPU

Start contributing in one click.

After the initial setup, you control the CPU slider and press Start. Your engines run locally; only the chess records are shared.

01

Download the Contributor

Get the repository ZIP, unzip it, and install Python, Git, GitHub CLI and Fastchess once.

02

Sign in and select files

Run gh auth login once. Open Start-Contributor.cmd and select trusted Stockless, challenger, Fastchess and PGN/EPD.

03

Set CPU and press Start

Choose concurrent games; after the real match, GitHub Actions checks PGN + EPD and publishes them automatically.
