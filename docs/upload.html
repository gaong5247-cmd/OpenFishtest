01

기존 파일 선택

윈도우 대국 결과 폴더에 있는 두 파일만 필요해.

♞
games.pgn 클릭하거나 PGN 파일을 여기에 드래그 PGN 최대 2,000,000바이트
♙
openings.epd 클릭하거나 EPD 파일을 여기에 드래그 EPD 최대 512KiB · 대국에 사용한 정규화 북

원본 200MiB 북을 직접 올리는 곳은 아님. Contributor가 생성한 openings.epd를 선택해 줘. 이 게시 방식은 PGN 최대 2MB, EPD 최대 512KiB야.

02

GitHub 관리자 인증

공개 HTTPS 백엔드 없이 GitHub에 바로 보냄.

관리자 전용 · 중요한 권한

GitHub 저장소 gaong5247-cmd/OpenFishtest에만 권한이 있는 짧은 만료기간의 Fine-grained PAT를 사용해. Repository permissions에서 Contents: Read and write만 부여하면 돼. 이 토큰은 저장소 변경 권한이 있으니 다른 Contributor에게 주면 안 됨.

GitHub 토큰 만들기 ↗

토큰은 이 탭의 입력창에만 유지되며 저장하거나 GitHub Pages에 기록하지 않아. 입력 내용은 api.github.com으로만 전송돼. 하지만 이 토큰으로 저장소를 수정할 수 있으므로 사용 후 폐기하거나 만료시키는 걸 권장해.

GitHub 인증 필요
두 파일을 선택하고 GitHub 권한을 확인해 줘.

게시되는 과정

01파일 업로드

브라우저에서 기보 두 개를 GitHub 임시 데이터 브랜치에 저장.

02Actions 자동 검사

신뢰된 main 코드가 수순·흑백 교대·EPD 일치를 검사. 실행파일·코드는 허용하지 않음.

03바로 공개

검증에 통과하면 PGN·EPD와 점수를 사이트에 게시. 실패하면 같은 파일로 다시 시도 가능.

PGN 형식이 정상이어도 특정 엔진이 실제로 둔 수인지 독립적으로 증명되지는 않아. 그래서 이 게시물은 커뮤니티 제출·엔진 출처 미검증 기록으로 공개하고 공식 Elo 랭킹에는 자동 반영하지 않음. 일반 Contributor는 원클릭 프로그램과 기존 PR 방식을 계속 이용할 수 있어.
♞ OPENFISHTEST GitHub Pages는 정적 사이트이며, 파일은 GitHub 저장소에 보관돼. 토큰은 이 페이지에서 보존되지 않음.
